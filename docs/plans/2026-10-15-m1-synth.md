# M1: Brook synth and the strip grammar

Spec: `docs/feature-spec.md` F0.2, F0.4–F0.7, F1, F4 and owner decision 1 (presets).
Layout: `docs/adr/0002-screen-layout.md`, `docs/mockups/Main.dc.html`.

Milestone build: the owner can install it, play the 4-voice synth from the keys, shape it
with the four strips, Shift and the section rail, and pick any of the 16 presets.

Not in M1: sequencer, drums, tape, mixer screen, FX, autosave. The other screen tabs and
slots 2–8 are shown but disabled (dimmed, no action, no dialog).

## Shared contract (written first, both modules code against it)

- `engine/core/include/groove/SynthParams.def`: the parameter table (IDs, keys, ranges,
  defaults, curves). C++ includes it as an X-macro. A Kotlin unit test parses it and checks
  that every key the UI layout names exists, and that the curve order matches `Curve`.
- `app/.../engine/ParamSpec.kt`: a Kotlin mirror of one table row.
- `app/.../engine/NativeEngine.kt`: the JNI API (notes with velocity, params, presets,
  stats including callback load). Values cross JNI in real units.

## Engine module (`engine/**`)

Tests first (GoogleTest, offline render) for every criterion marked [H] in F1 and F0.5–F0.7.

- `SynthParams.h`: enum from the .def, a constexpr metadata table, and `ParamStore`
  (`std::array<std::atomic<float>, N>`, written by the control thread and read once per
  block by the audio thread).
- DSP blocks: oscillator (PolyBLEP saw / BLEP square with PW / triangle / sine, morph by
  Wave), sub (−1 oct square), noise (xorshift), ADSR (exponential, retrigger from current
  level), a 24 dB/oct resonant low-pass (TPT ladder with tanh drive, self-oscillates at
  max resonance), a one-pole high-pass, and an LFO (4 shapes, delay, retrigger, tempo sync
  at a fixed 120 BPM until M2).
- `Voice`: oscillator, sub and noise → HPF → ladder → amp. Modulation: filter env, key
  tracking, velocity, LFO.
- `SynthEngine` (replaces `SynthCore`): 4 voices; poly, mono (legato, last-note priority
  via `MonoNoteStack`) and unison (4 voices, ±10 c); glide; voice stealing per F1.1 with a
  2 ms fade. Same event queue and `NoteOnRender` latency records as `SynthCore`, with velocity added.
- Per-parameter smoothing (10 ms or less) per F0.7.
- `MasterBus`: a soft limiter with the ceiling at −0.3 dBFS (F0.6).
- `Presets`: 16 original presets (bass, lead, pad, pluck, fx) as full value sets.
- Android: `AudioEngine` measures each callback's render time with
  `clock_gettime(CLOCK_MONOTONIC)` (vDSO, no lock) into atomics (mean, and the max over a
  window); the JNI bridge implements `NativeEngine.kt`.

## UI module (`app/**` except `engine/NativeEngine.kt` and `engine/ParamSpec.kt`)

Pure Kotlin models first, with JUnit tests (criteria [K] in F4):

- `ParamMapping`: normalised 0..1 ↔ value per curve; display formatting ("2.4k", "Saw",
  "120 ms", "+40%", enum labels).
- `StripGesture`: a drag over 1.5 strip heights covers the full range; a second finger gives
  ¼ speed; double-tap resets to default; a 500 ms long-press toggles the lock.
- `ShiftState`: a tap latches; holding past 300 ms is momentary.
- `SynthLayout`: sections Osc, Filter, Env, Mod × main and Shift → param keys (feature spec F1 table).

Compose UI per the mockup: top bar (tabs, 8 slots, tempo readout, transport shown but
disabled in M1, Shift), section rail plus display (waveform, filter curve and envelope
drawn from live values), four strips, and the two-octave polyphonic keyboard. Velocity
comes from where the key is touched: 0.5 at the top, 1.0 at the bottom. Long-press slot 1
to open the preset strip over the keys; tap a preset to load it, tap outside to close.
A small debug toggle shows tap-to-tone, xruns, callback load and the burst setting (F0.2, F0.4).
