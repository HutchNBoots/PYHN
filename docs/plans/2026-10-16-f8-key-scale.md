# Increment 1.1a: key and scale (F8)

Spec: `docs/feature-spec.md` F8 (approved with defaults). UI and storage only; no engine change (F8.8).

- **Pure model `Scale`:** the 11 scales plus Off as interval sets; `inKey(note)`; `isRoot(note)`;
  `step(note, ±1)` to the next in-key note; tests for every key and scale (F8.1, F8.4).
- **Session state:** key and scale are global, saved in session format v2 with a v1 → v2
  migration to Off (F8.5), and they mark the session dirty like any other change.
- **Seq screen:** the Shift layer (no step selected) gets Key and Scale strips in the two
  disabled slots.
- **Display:** "A minor" (key and scale) shows on the synth and Seq screens while a scale is on.
- **Keyboard (synth slots only):**
  - With a scale on, the keyboard's touch gate ignores touch-downs and slides onto out-of-key
    keys, which are drawn dimmed. Root pads get an accent stripe (F8.2, F8.3).
  - A held note is never cut.
  - The drum slot is unchanged (F8.7).
- **Note strip and pads:**
  - On a selected step, the Note strip moves through in-key notes only.
  - Out-of-key steps keep playing and get a small mark on their pad (F8.6).
